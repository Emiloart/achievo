# UX Backlog (Post-P0)

This backlog captures UX work that is out of scope for the P0 foundation pass. It is grounded in existing routes and backend capabilities.

## High Priority
1) Dashboard composability
- Break dashboard into typed, reusable domain widgets
- Add query caching for heavy sections (goals, badges, quests)

2) Program discovery UX
- Add program listing views under /orgs/:handle
- Improve milestone submission UX (stepper + progress)

3) Validation request wizard
- Guided flow for selecting validator and evidence
- Inline attestation status and anchor visibility

4) Marketplace settlement UX
- Payment rail visibility (if escrow added later)
- Per-trade activity timeline

5) Privacy tooling
- Visualize privacy overrides and what is public
- Bulk visibility controls for proofs and validations

## Medium Priority
1) Projects
- Dedicated member management UI
- Invoice overview and billing dashboard
- Time tracking controls and reporting

2) Parties
- Party onboarding and invite UX
- Party activity feed improvements

3) Risk and consistency
- Explain scores and remediation steps

## Low Priority
1) Achievo admin tools
- Admin dashboard for chain actions and indexer
- Monitoring alert list with filtering

2) Achievo legacy views
- Legacy goals and badge history visualizer

## Open Questions
- Do we standardize on single verification layout across verify and share pages?
- Should profile sharing be expanded beyond current share links?
